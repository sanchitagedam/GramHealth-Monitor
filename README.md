# GramHealth Monitor

### A Rural Healthcare Facility Monitoring System

## About the Project
GramHealth Monitor is a web-based prototype designed to help monitor rural healthcare facilities. It provides a dashboard for viewing facility conditions, tracking reported issues, and monitoring their resolution status.

## Key Features
- Dashboard showing facility and issue statistics
- Health facility directory and search
- Facility reports covering staff, medicines, equipment, infrastructure, and services
- Issue tracking and status updates
- Report history
- CSV export for reports and issues
- Responsive layout for desktop and mobile screens

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the navigation menu to explore the dashboard, facilities, reports, and issues.

## Live Demo
https://sanchitagedam.github.io/GramHealth-Monitor/

## Important Limitations
This is a demonstration prototype that uses sample data stored locally in the browser. It does not connect to real healthcare facilities or a central database. Data is not automatically synchronized between devices.

**Note:** Do not enter real patient information.

## Future Improvements
- Secure database integration
- User authentication and role-based access
- Centralized facility data synchronization
- Notifications for critical issues
- Integration with verified healthcare facility records

## Project Purpose
The project aims to demonstrate how a simple digital monitoring system could help organize rural healthcare facility reports and identify issues that may require attention.
